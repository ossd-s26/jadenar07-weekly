# Git Exercise

A lot of the exercise felt intutive because I'm familiar with the many Git commands such as echo, clone, touch and more. I think my biggest takeaway was more so how git actually stores things. Learning that Git saves objects with references to eah other and essentially a chain of those to reach previous states of the files, is super cool. I also wasn't super in tune with the proper ways to recover deleted files and specific lines from commits. I feel a bit more confident in ther restorative measures that Git enables

# Project Evaluations

The project evaluation section perfectly encapsulates why I find picking an open source project very overwhelming, there's so many cool projects. I think it's really interesting to see how big projects like pandas, react and Brave have a good amount of good first issues. This surprised me since I thought projects of such scale wouldn't really have many since it's difficult to get into it, learn the repo and ultimately contribute. I'm most excited about contributing to something a big community is collectively working on. The biggest challenge is also something I look forward to, which is gaining a deeper understanding of the project, it's domain knowledge and likely complex code base. I plan to overcome them by just setting sometime aside to dive into the documentation and for the issue, trace back on important functions and files until I gain a good enough understanding
